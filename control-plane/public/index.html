Preferred workflow

One command from the system project.

The CLI builds a private immutable Linux image, uploads it, follows the trusted run, and returns structured feedback.

system-project/cvbench submit . --wait --json
pip install git+https://github.com/the-Drunken-coder/cvbench-benchmark.gitcvbench logincvbench doctor
